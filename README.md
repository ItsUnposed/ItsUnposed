### About

Ich baue Dinge, die aus Strom Verhalten machen. Mikrocontroller, Sensorik,
Motoren, und der Code dazwischen. Was auf dem Steckbrett anfängt, soll
irgendwann als eigene Platine enden.

Daneben lebe ich im Terminal. Debian mit i3, alles konfiguriert bis auf die
letzte Farbe, versioniert in einem eigenen Dotfiles-Repo.

```
aktuell         ESP32, C++, PlatformIO
als naechstes   KiCad und eigene Platinen
ziel            Elektrotechnik studieren
```
