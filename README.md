### About

Ich baue Dinge, die aus Strom Verhalten machen. Aktuell Schüler mit Ziel
Elektrotechnik, mit Fokus auf Mikrocontroller, Sensorik und alles, was sich
löten oder skripten lässt.

- Arbeite gerade an einem getriebenen Desktop-Roboter mit ESP32 und OLED-Gesicht
- Zuhause auf Debian mit i3, alles in einem eigenen Dotfiles-Repo
- Lerne KiCad und PCB-Design, um vom Steckbrett wegzukommen
- Erreichbar über GitHub Issues oder die Mail im Profil
